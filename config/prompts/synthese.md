# opdracht

Assembleer alle secties tot één markdown-rapport. Schrijf bovenaan:

```
# {{report_title}}
```

Dan elke sectie in de gegeven volgorde.

Taken per sectie:
1. Controleer de openingszin: bevat die de kern? Zo niet, herschrijf.
2. Verwijder overbodige herhalingen tussen secties.
3. Zorg voor natuurlijke overgangen: elk nieuwe sectie bouwt logisch voort op de vorige.
4. Pas de stijlgids consequent toe: geen em-dashes, geen Title Case, geen clichés.
5. Pas de lengte aan waar nodig: schrap wat niet bijdraagt.

Geef alleen het volledige rapport terug als markdown, zonder inleidende tekst of afsluitende uitleg.
